# AI-Based Legal Document Assistant

An AI-powered assistant designed for analyzing, summarizing, and managing legal documents.

## Features

- **Document Analysis**: Summarize and extract key terms from legal documents.
- **Contract Review**: Highlight potential risks, clauses, and obligations.
- **Intelligent Search**: Query legal documents using natural language.
